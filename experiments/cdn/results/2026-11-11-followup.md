# CDN reader comparison, 2026-11-11

- Release `nmbs-sncb-20261111-5c05082d` (coverage 2026-11-08 to 2027-01-13).
- Data: 16 files = 4 tables + 12 consecutive connection pages; every column of every file is decoded into Python lists.
- Machine: x86_64, 16 CPUs, Python 3.12.13, Linux 7.2.15-300.fc45.x86_64. **Not a Raspberry Pi or other Home Assistant-class device.**
- Time: best and median of 3 passes in one process. Peak RSS is the process peak (one pass held in memory at a time), with its value before reading in brackets (the stdlib reader imports `pyrail`, which loads aiohttp).
- Installed size: files of the distribution(s) in this environment; `stdlib` adds nothing.

Why a reader failed:

- nanoarrow: `NanoarrowException: ArrowArrayStream::get_schema() failed (22): Unexpected message type at start of input (expected Schema)`

The CDN files have no Schema message before the record batches (see `check_schema_message.py`); the same table written as an IPC stream is readable (see `probe_nanoarrow.py`).
